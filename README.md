# 📊 连板股票数据分析展示工具（只有主板，不包含创业板和科创板）

> A股连板股票实时数据分析工具 —— 专注于连板股的竞价数据、实时走势、AI强度评分、量价趋势与主力资金趋势分析

## 📖 项目简介

本工具是一款专注于**A股连板股票**的实时数据分析与展示工具。通过抓取公开市场数据，提供连板股票的**竞价分析**、**AI强度评分**、**量价趋势**和**主力资金趋势**等多维度数据展示，帮助用户更直观地了解连板股的市场表现。

**本工具定位为数据展示与分析参考工具，不提供任何投资建议。**

## ✨ 主要功能（部分功能未发布）

| 功能模块 | 说明 |
|---------|------|
| 📋 **连板天梯** | 按连板数分组展示前一日部分强势连板股票（前一日的2板/3板/4板/5板+） |
| 🤖 **AI强度评分** | 基于量化模型对强势连板股票生成的强度评分（数据仅供参考） |
| 💰 **竞价数据分析** | 9:20/9:25竞价封单量、竞价额、竞比等关键竞价数据 |
| 📈 **量价趋势** | 实时量价变化趋势分析 |
| 💵 **主力资金趋势** | 主力资金净流入/流出趋势追踪 |
| ⚡ **实时预警** | 自定义条件钉钉自动预警|
| 📤 **数据导出** | CSV格式数据导出 |
